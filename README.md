<h1 align="center">any-to-anki</h1>

<p align="center">
<strong>any-to-anki</strong> is a agent skill that allows you to convert any text into Anki cards.
</p>

Normally you would study a topic, and then manually create Anki cards for each concept.
This is a tedious process, and it's easy to make mistakes.
What if we shift this process and use Agent to create cards for us and then we study the cards?
